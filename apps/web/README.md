# Textzi web

Vue 3 + Vite + TypeScript + Vuetify (Vuexy admin theme) frontend for Textzi — see the
[repo root README](../../README.md) for the full setup, environment variables, and deployment
notes.

```sh
pnpm install
pnpm dev      # local development, hot reload
pnpm build    # production build (output: dist/)
pnpm typecheck
```
